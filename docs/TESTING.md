# What is tested, and what each test can and cannot prove

## Simulated billing vs real Google Play — read this first

Nothing in the automated suites talks to the real Google Play. **No real payment, trial, renewal or cancellation has been tested.**
The automated tests use a *pretend Google Play* that can be told to answer "subscribed", "cancelled", "nothing", "error", and so on.
They prove that **the app does the right thing given each answer**. They cannot prove that **Google gives those answers** in the
way the app expects; only a real phone, a licence-tester account and the Play Console can show that (see the last section).

| Layer | How | Real or simulated? | Proves |
| --- | --- | --- | --- |
| Subscription rules, offline grace, clock-rollback guard, sealed memory (`src/billing/*.test.ts`) | Vitest | Simulated Google answers; real logic | Every state is handled: active, trial, cancelled-until-end, ended, pending, refunded, grace/hold, unreachable, unsupported |
| Paywall, gate, Settings (`src/ui/screens/Paywall.test.tsx`) | Vitest + Testing Library | Simulated Google | The right screen for each state; nothing opens without a subscription |
| Subscription lifecycle in a browser (`e2e/subscription.spec.ts`) | Playwright against `npm run build:mock` | Simulated Google | The same, end to end, with real clicks, restarts, offline mode |
| Onboarding order, 14 languages, persistence (`e2e/onboarding.spec.ts`) | Playwright | Simulated Google for the trial step | language → name → trial → currency → goal; every language selectable |
| Layout at 320 × 568, 390 × 844, 768 × 1024, 1280 × 800 in 14 languages; Arabic/Urdu mirroring (`e2e/i18n.spec.ts`) | Playwright | n/a | No overflow or clipped text on any screen, sheet or paywall |
| Accessibility of every screen and paywall state (`e2e/a11y.spec.ts`) | axe-core | n/a | No serious WCAG 2 A/AA violations |
| Purchase signature check and Keystore stamp maths (`android/app/src/test/.../*Test.java`) | JUnit on a plain JVM | **Real** signature algorithm, real RSA/HMAC; Google's key pair is generated by the test | A purchase not signed by the licence key's owner is rejected; an edited or foreign stamp is rejected |
| Release bundle contains no test billing | `npm run verify:release` | Real bundle | Nothing from the pretend Google Play ships; CSP intact |
| Real build on GitHub's servers | `.github/workflows/ci.yml` (jobs `test` and `android`), real Android SDK, Gradle, Play Billing Library 9.1.0, Capacitor 8.5.2, Chrome 153 | **Real toolchain; simulated Google Play** | Observed green on commit `5527678`: the app **compiles** including the native billing plugin; native JUnit tests pass; a debug APK is assembled; a release build **refuses** to run without the licence key; a **signed release bundle** builds with R8 shrinking (throwaway key, discarded); the whole browser suite passes in Chrome 153 |

## Commands

```bash
npm run typecheck && npm run lint
npm test                    # unit + component tests
npm run test:e2e            # browser tests (builds the mock-billing app first)
npm run verify:release      # real build + check that no test billing is inside
# native JUnit (needs the Android SDK / Android Studio): cd android && ./gradlew testDebugUnitTest
```

## Secret scan

Before committing run `bash scripts/scan-secrets.sh` (also run by CI). It looks for private keys, service-account files, keystores, `keystore.properties`
and common API-secret formats in every file git knows about, and fails if it finds any.

## Real Google Play test (manual — the only test that proves payments work)

Do this on a real phone after the first build is in Internal testing (steps in `docs/PLAY_CONSOLE_CHECKLIST.md`):

1. Install from the Play Store opt-in link with a **licence-tester** Google account. → app opens on language, name…
2. At the trial step the price reads **€2.99** (or your country's equivalent) and "7 days free"; tap *Start free trial* → Google's sheet
   shows a "test card, always approves" option → complete → the app continues. **Pass:** you are not charged; access unlocks.
3. Close and reopen the app; switch to airplane mode and reopen. **Pass:** still open.
4. Play Store → profile → *Payments & subscriptions* → *Subscriptions* → Freelanche → *Cancel*. Back in the app (pull it forward): Settings
   says "Cancelled — active until the end of the paid period". **Pass:** still open until the (accelerated) period ends, then locked
   with "Your subscription has ended" and your data intact.
5. Reinstall or use a second phone with the same account → *Restore purchases* (or just open). **Pass:** unlocked again if still active.
6. A second Google account that is *not* subscribed. **Pass:** paywall only; export still works.
7. Arabic: pick العربية on the first screen. **Pass:** whole flow right-to-left.
8. Let the accelerated trial (≈3 min) convert to paid and renew a couple of times (≈5 min each). **Pass:** stays unlocked.

Write down what you saw. If any step differs, that is a real finding, not a test problem.

## What the CI build does *not* prove

* It uses a **throwaway** signing key and a **dummy** licence key, and discards the bundle — it proves the release *pipeline* works, not that any file is ready to upload.
* It never runs the app on a phone or emulator, so it cannot show that the WebView, the Billing bridge and R8 shrinking work together at run time. The manual phone test above does.
* It never talks to Google Play.
